# 連絡帳の下書きを作る

保護者が連絡帳の文章や食事の写真を送ってきたら、この順で進める。保護者が忙しい朝なので、聞くことは最小限にして、1 回の返事で確かめられる形にする。

コドモンの連絡帳は欄が分かれていて、まとめて貼り付けられない。このスキルの芯は、保護者が書いた文章を受け取って、欄ごとに分けて入れること。

## 0. どこから取るか

欄ごとに、次の順で先にある物を使う。

1. **保護者が書いた文章**: 書いてある欄は、そのまま採る。言い回しを直したり、ぴよログや写真の内容で上書きしたりしない。食い違いがあっても保護者の文章を採り、確かめたいことに一言添えるだけにする
2. **写真**: 食事の欄（2 を見る）
3. **ぴよログ**: 排便・睡眠・体温・コメント（1 を見る）。使っていない家庭もある

## 夜に入れる時、朝に仕上げる時

連絡帳は、夜と朝に分けて少しずつ入れられる。

- **夜など、連絡帳を出す前に文章や写真が届いた時**: 確認を待たず、届いた分だけをその場で下書き保存する（4 を見る）。聞き返さない。終わったら、入れた欄とまだ空の欄を短く伝える
- **朝、「連絡帳お願い」と言われた時や、残りが届いた時**: まず `python3 scripts/codmon_fill.py --read` で入っている内容を読む。入っている欄は聞き直さず、空の欄だけを埋めて、全体を見せて確かめる（3 を見る）

下書きなので、送信を押すまで園には届かない。

保護者の文章は形が決まっていない（「夜 カレー完食」「体温36.5 7時」「お迎え18時パパ」など）。どの欄の話かを読み取って分ける。どの欄か分からない文は、コメントの欄に入れて、確かめたいことに挙げる。

## 聞かないこと

保護者はいそがしい朝に答えている。次は聞かずに決める。同じことを 2 回聞かない。

- **ぴよログに記録が無い排便**: 0 回とする。「うんちが出ない日もある」。回数や状態を聞かない（ぴよログを使っている家庭だけ）
- **体調・メモが無い**: コメントは空にする。「様子はふだん通りですか」と聞かない
- **保護者が残した物だけを言った時**: ほかは全部食べた。「ほかは全部食べましたか」と聞かない
- **写真が 1 枚の食事**: 完食とする（2 を見る）
- **体温の測定時間**: 15 分刻みに丸めた値を、はじめから下書きに書く（8:10 → 8:15）

聞いてよいのは、朝に仕上げる時に、連絡帳に要るのに、保護者の文章・写真・ぴよログのどこにも無いものだけ。睡眠（ぴよログに無い時）、お迎えの時間と誰、写真で確からしさが低い品目。ぴよログを使っていない家庭では、排便・体温もここに入る。まとめて 1 回で聞く。

## 1. ぴよログの記録を読む

環境変数 `PIYOLOG_FEED_URL` が無ければ、ぴよログを使っていない家庭なので、この手順は飛ばす。使うように勧めない。

```
python3 scripts/piyolog_summary.py
```

直近 24 時間の体温・食事・うんち・睡眠・体調・メモがまとまって出る。失敗したら `python3 scripts/setup_check.py --human` で原因を確かめ、`docs/setup.md` のどこが足りないかを保護者に伝える。

## 2. 写真から食事を読む

写真は 1 食につき 1 枚か 2 枚上がってくる。

- **1 枚**: 食べる前の写真。全部食べたものとして「完食」と書く
- **2 枚**: 食べる前と食べた後の写真。2 枚の差から、品目ごとにどれだけ食べたかを書く。後の写真に残っている量で、完食・ほとんど・半分くらい・少し・食べなかった のどれかにする

進め方:

- まず写真を食事ごとに分ける。同じ器・同じ献立が写っている写真が同じ食事。晩ごはんか朝ごはんかは、ぴよログの食事の時刻、写真の明るさや献立から決める。迷ったら保護者に聞く
- 2 枚の組では、料理が多く残っている方を食べる前とする。どちらが前か分からなければ保護者に聞く
- 品目を、確からしさ（高い・中くらい・低い）付きで挙げる。低い物は書かずに保護者に聞く
- 1 食に 3 枚以上ある時や、組にならない写真がある時は、どれがどの食事の前・後かを保護者に聞く
- 写真に写った子どもの様子（顔色など）は、保護者が気にしていそうな時だけ一言添える。診断はしない

連絡帳の食事の欄の書き方:

- 主食（ごはん・パンなど）も必ず品目に入れる。残した物があっても品目からは外さない
- 全部完食なら、品目を並べて最後に「（全て完食）」: `パン、バナナ、ヨーグルト、牛乳（全て完食）`
- 一部だけ残した時は、品目を全部並べて最後にまとめる: `ごはん、ハンバーグ、みかん、牛乳（ごはんは半分、ほかは完食）`
- いくつも残した時は、品目ごとに量を付ける: `カレー（半分くらい）、サラダ（少し）、ぶどう（完食）`

## 3. 連絡帳の下書きを見せて確かめる

保護者の文章・写真・ぴよログをまとめて、**コドモンの画面と同じ欄・同じ並び**で下書きを 1 回で見せる。どこから取ったか（文章・写真・ぴよログ）は書かない。分からない所は「？」にして、下にまとめて聞く。

例:

```
排便
  夜: 0回
  朝: 普通 1回
食事
  夜: ごはん、カレー、ぶどう、牛乳（ごはんは半分、ほかは完食）
  朝: パン、バナナ、牛乳（全て完食）
検温: 36.8℃（6:15）
睡眠
  入眠: 20:45
  起床: 6:00
お迎え予定時間: 18時 ／ パパ
コメント: 朝だけ少しせき

確かめたいこと: 写真の茶色の丸いものは何ですか？
```

保護者の言い直し（「茶色いのは栗」「今朝ちょっと鼻水」など）を反映して、もう一度見せる。保護者が「OK」と言うまで入力に進まない。

## 4. コドモンに入力して下書き保存する

朝に仕上げる時は保護者が OK と言ったら、夜に入れる時はすぐに、下書きを `tmp/draft.json`（git に入らない）に書き、保存まで進める。欄と値の決まりは `docs/codmon-form.md`。

```
python3 scripts/codmon_fill.py tmp/draft.json --save
```

- `draft.json` の形はスクリプトの先頭に書いてある。分からない欄は書かない（空のまま残る）
- 排便の状態は 普通・軟便・少量便・硬便・下痢便 のどれか。回数は 3 を超えたら 3
- `draft.json` に書いた欄だけが変わり、ほかの欄は入っている内容のまま残る
- 開く連絡帳は、午前は今日、12 時以降は明日。次の登園日が明日でない時（金曜の夜など）は保護者に聞いて `--date 2026-11-09` のように指定する
- 書いた欄に別の内容がすでに入っていると、何も変えずに止まり（終了コード 2）、入っている内容を表示する。保護者に見せて、上書きしてよいと言われた時だけ `--overwrite` を付けてやり直す
- 開いた日の連絡帳がもう送信済みだと、何も変えずに止まる。そのまま保護者に伝える
- 保存した後に開き直して値を読み直す。入れた値が残っていなければ止まる（終了コード 3）。もう一度実行する
- お迎えは `"13時\nママ"` のように、時間と誰を改行で分ける
- 終わったら、表示された値（`values`）を保護者に見せて、下書きの中身と合っているか確かめる

送信は押さない。朝に仕上げたら「コドモンのアプリで内容を見て、送信を押してください」と伝えて終わる。`tmp/draft.json` は終わったら消す。
