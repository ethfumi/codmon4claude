# 連絡帳の下書きを作る

**保護者の手間を減らすのが最優先。往復はなるべく少なく、返事の文章は短く。**

保護者は写真と文章を送ったら会話を閉じ、あとはコドモンのアプリで内容を見て送信するだけ、という使い方を目指す。下書きなので、送信を押すまで園には届かない。違っていれば、保護者が送信する前にアプリで見て、話して直せる。

そのため、次のようにする。

- 確認を待たずに、届いた分だけですぐ下書き保存する
- 聞き返さない。分からない物は、いちばん近い物で入れるか、空のまま保存する。空いている欄は返事で伝わり、保護者があとで話せばよい
- 会話の中で聞くのは、次の登園日を決める時（4 を見る）だけで、1 回まで

コドモンの連絡帳は欄が分かれていて、まとめて貼り付けられない。このスキルの芯は、保護者が書いた文章を受け取って、欄ごとに分けて入れること。上から順に、1 受け取る → 2 読む → 3 欄に分ける → 4 すぐ下書き保存する → 5 返事する、と進める。

## 1. 受け取る

- 夜も朝も、届いた分だけで進める。連絡帳は夜と朝に分けて少しずつ入れられる
- 朝、「連絡帳お願い」と言われた時や、残りが届いた時は、まず `python3 scripts/codmon_fill.py --read` で入っている内容を読む。入っている欄はそのままにして、空の欄だけを埋める
- 保護者の文は音声入力の文字起こしのことがある。打ち間違いや同音の取り違え（「じゅうはちじはん」→ 18:30）は、読みの近い言葉で読み取る。形も決まっていない（「夜 カレー完食」「体温36.5 7時」「お迎え18時パパ」など）

## 2. 読む

### ぴよログ

環境変数 `PIYOLOG_FEED_URL` が無ければ、ぴよログを使っていない家庭なので、飛ばす。使うように勧めない。

```
python3 scripts/piyolog_summary.py
```

直近 24 時間の体温・食事・うんち・睡眠・体調・メモが出る。失敗したら `python3 scripts/setup_check.py --human` で原因を確かめ、`docs/setup.md` のどこが足りないかを保護者に伝える。

### 前の 30 日の連絡帳

会話の始まりに裏で読まれ、読み終わると `tmp/notebook_history.json` に置かれる。`days` に日ごとの全部の欄、`usual` にいつもの値（draft.json と同じ形。お迎えは曜日ごとの `pickup_by_weekday`、食事はいつも入っている品目の `meal_morning_items`・`meal_night_items`、コメントは同じ書き方が 2 回以上あった時だけ。入っている日が半分に届かない欄は、いつもは空なので出ない）。使い方は 3。

- 無ければ待たずに進める。同じ会話で一度読んだ物は、読み直さない
- 読んだ内容はこの会話の中だけで使い、リポジトリのファイルに書かない

### 写真

1 食につき 1 枚か 2 枚上がってくる。

- **1 枚**: 食べる前の写真。完食とする
- **2 枚**: 食べる前と後。後に残っている量で、品目ごとに 完食・ほとんど・半分くらい・少し・食べなかった のどれかにする。料理が多く残っている方を前とする
- 同じ器・同じ献立が写っている写真が同じ食事。晩ごはんか朝ごはんかは、ぴよログの食事の時刻、写真の明るさや献立から決める
- どれがどの食事の前・後か分からない時（前後が決まらない、3 枚以上ある、組にならない）は、その食事の欄を空けておく
- 確からしさが低い品目も、いちばん近い料理の名前で入れる。下書きに「？」などの印は付けない（合っていても保護者が消す手間が出る）。返事でお知らせを添える（5）
- 写真に写った子どもの様子（顔色など）は、保護者が気にしていそうな時だけ一言添える。診断はしない

## 3. 欄に分ける

欄ごとに、次の順で先にある物を使う。足りない欄だけを埋める。

1. **保護者が書いた文章**: そのまま採る。言い回しを直したり、ぴよログや写真の内容で上書きしたりしない。食い違っても保護者の文章を採る
2. **ぴよログ**: 排便・睡眠・体温・コメント
3. **写真**: 食事の欄
4. **いつもの値**（`usual`）: 排便・睡眠・体温・お迎え（開く日の曜日の値）・コメント。食事は、写真も文章も無い時に、いつもの品目へ主食（前の日々の朝・夜の主食に合わせて「パン」「ごはん」など）を足して、それらしく入れる（`パン、バナナ、ヨーグルト、牛乳（全て完食）`）。返事でお知らせを添える（5）

下書きには、いつもの値で入れた印を付けない。保護者が「いつもの値で入れた所を下書きでも分かるようにして」のように頼んだ時だけ、その会話の間は、いつもの値で入れた欄の末尾に「（いつもの）」を付ける。

どの欄か分からない文は、コメントの欄に入れる。

### 夜に送られた言葉

夜に開くのは次の朝に出す連絡帳なので、「今日」「明日」を連絡帳の中の夜と朝に読み替える。

- 「今日の晩ごはん」「今日は 18 時半に寝た」「今夜のうんち」: 夜の欄（食事 夜、排便 夜）と入眠
- 「明日の朝は〜」「朝ごはんはパンの予定」「明日のお迎えは 18 時パパ」: 朝の欄（食事 朝、排便 朝）、起床、検温、お迎え予定時間、コメント。まだ起きていない朝のことも、そのまま入れておく

### 決めておくこと

- ぴよログに記録が無い排便: 0 回（ぴよログを使っている家庭だけ。記録が無いのは出ていないということなので、いつもの値は使わない）
- 体調・メモが無い: コメントは空
- 保護者が残した物だけを言った: ほかは全部食べた
- 体温の測定時間: 15 分刻みに丸める（8:10 → 8:15）
- いつもの値も無い欄: 空のまま

### 食事の欄

- `tmp/notebook_history.json` があれば、`days` の食事の欄に出てくる料理名を写真の候補にし、見た目が似ていればその名前を使う。書き方（品目の並べ方、区切りの記号、「完食」などの言い方、句読点）も前に合わせ、下の例と違えば前を優先する
- 主食（ごはん・パンなど）も必ず品目に入れる。残した物があっても品目からは外さない
- パンの種類が写真で分からなければ、種類を当てずに「パン」と書く
- 全部完食: `パン、バナナ、ヨーグルト、牛乳（全て完食）`
- 一部だけ残した: `ごはん、ハンバーグ、みかん、牛乳（ごはんは半分、ほかは完食）`
- いくつも残した: `カレー（半分くらい）、サラダ（少し）、ぶどう（完食）`

## 4. すぐ下書き保存する

下書きを `tmp/draft.json`（git に入らない）に書き、保存する。欄と値の決まりは `docs/codmon-form.md`。実行の前に「コドモンに保存します。10 秒ほどかかります。アプリを閉じても進みます」と伝える。

```
python3 scripts/codmon_fill.py tmp/draft.json --save
```

- `draft.json` の形はスクリプトの先頭に書いてある。書いた欄だけが変わり、書かない欄は入っている内容のまま残る
- 排便の状態は 普通・軟便・少量便・硬便・下痢便 のどれか。回数は 3 を超えたら 3
- お迎えは `"13時\nママ"` のように、時間と誰を改行で分ける
- 開く連絡帳は、午前は今日、12 時以降は明日。次の登園日が明日でない時（金曜の夜など）だけ、保存の前に 1 回聞いて `--date 2026-11-09` のように指定する。答えが無ければ決まりどおりの日。決まった日はこの会話の間ずっと使う
- 書いた欄に別の内容が入っていると、何も変えずに止まる（終了コード 2）。保護者に見せて、上書きしてよいと言われた時だけ `--overwrite` を付ける。保護者の言い直しで入れ直す時は、上書きしてよいものとする
- 送信済みの日だと、何も変えずに止まる。そのまま保護者に伝える
- 保存した後に読み直して、入れた値が残っていなければ止まる（終了コード 3）。もう一度実行する
- 表示された値（`values`）が下書きと合っているかを自分で確かめる

送信は押さない。`tmp/draft.json` は終わったら消す。保護者の言い直し（「さつまいもじゃなくて栗」「今朝ちょっと鼻水」など）が届いたら、その欄を入れ直して保存する。

## 5. 返事する

保存した後と `--read` した後は、開いた日と空いている欄だけを 1〜2 行で返す。実行結果の `date` と `empty` から作り、自分の記憶で書かない。写真から推測して入れた品目と、いつもの値で入れた欄がある時だけ、確認を求めないお知らせをそれぞれ 1 行で添える。保存した値に合っていない欄があった時だけ、その欄を書く。

```
11月9日(月)の連絡帳に保存しました。
空いている欄: 検温、お迎え予定時間。このまま話してください
朝ごはんの「さつまいも」は写真から推測して入れました。違っていたら教えてください。
朝ごはん・睡眠・お迎えは、いつもの値で入れました。違っていたら教えてください。
```

空いている欄が無ければ、「全部の欄が埋まりました。コドモンのアプリで内容を見て、送信を押してください」とだけ書く。

保護者が「全部見せて」「今どうなってる？」と頼んだ時だけ、`--read` の結果をコドモンの画面と同じ欄・同じ並びで見せる。入っていない欄は「（空）」と書く。この会話で入れた値には、値の後ろにどこから取ったかを短く書く（下書きには書かない）。例えば次のように書き、ほかの所から取った時は、それに合わせた言い方にする。

- 保護者が送った言葉から: 「（音声より）」
- ぴよログから: 「（ぴよログより）」
- 写真から: 「（写真より）」
- いつもの値、3 の「決めておくこと」、写真から推測した品目: 「（推測）」

```
排便
  夜: 0回（推測）
  朝: 普通 1回（ぴよログより）
食事
  夜: ごはん、カレー、ぶどう、牛乳（ごはんは半分、ほかは完食）（写真より）
  朝: パン、バナナ、ヨーグルト、牛乳（全て完食）（推測）
検温: 36.8℃（6:15）（ぴよログより）
睡眠
  入眠: 20:45（ぴよログより）
  起床: 6:00（推測）
お迎え予定時間: 18時 ／ パパ（音声より）
コメント: 朝だけ少しせき（音声より）
```
