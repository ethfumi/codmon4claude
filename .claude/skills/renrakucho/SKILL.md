# 連絡帳の下書きを作る

**保護者の手間を減らすのが最優先。往復はなるべく少なく、返事の文章は短く。**

保護者は写真と文章を送ったら会話を閉じ、あとはコドモンのアプリで内容を見て送信するだけ、という使い方を目指す。届いた分はすぐ下書き保存し、保護者の確認を待たない。下書きなので、送信を押すまで園には届かない。確かめるのは保護者が送信する前のアプリで足りるので、違っていれば保護者が話して直せる。

コドモンの連絡帳は欄が分かれていて、まとめて貼り付けられない。このスキルの芯は、保護者が書いた文章を受け取って、欄ごとに分けて入れること。

上から順に、1 受け取る → 2 読む → 3 欄に分ける → 4 すぐ下書き保存する → 5 返事する、と進める。

## 1. 受け取る

保護者が送ってきた物を、そのまま受け取る。聞き返さない。

- 夜も朝も、文章や写真が届いたら、届いた分だけで進める。連絡帳は夜と朝に分けて少しずつ入れられる
- 朝、「連絡帳お願い」と言われた時や、残りが届いた時は、まず `python3 scripts/codmon_fill.py --read` で入っている内容を読む。入っている欄は聞き直さず、空の欄だけを埋める
- 保護者の文は音声入力の文字起こしのことがある。打ち間違いや同音の取り違え（「じゅうはちじはん」→ 18:30）は、読みの近い言葉で読み取る。文に区切りが無くても、欄ごとに分ける
- 保護者の文章は形が決まっていない（「夜 カレー完食」「体温36.5 7時」「お迎え18時パパ」など）

保存した後に確かめることはしない。会話の中で聞くのは、次の登園日を決める時（4 を見る）だけで、1 回まで。

## 2. 読む

### ぴよログ

環境変数 `PIYOLOG_FEED_URL` が無ければ、ぴよログを使っていない家庭なので、この手順は飛ばす。使うように勧めない。

```
python3 scripts/piyolog_summary.py
```

直近 24 時間の体温・食事・うんち・睡眠・体調・メモがまとまって出る。失敗したら `python3 scripts/setup_check.py --human` で原因を確かめ、`docs/setup.md` のどこが足りないかを保護者に伝える。

### 前の 30 日の連絡帳

会話の始まりに、前の 30 日の連絡帳の食事の欄が裏で読まれ、読み終わると `tmp/meal_history.json` に置かれる（`meals` に日ごとの「食事 夜」「食事 朝」）。

- ファイルが無ければ、待たずに候補なしで進める
- 同じ会話で一度読んだ物は、自分で読み直さない（作業場所が立ち上がり直しても、今日読んだファイルは残して使う）
- 読んだ内容はこの会話の中だけで使い、リポジトリのファイルに書かない
- 使い方は 3 の食事の欄を見る（料理名の候補と、書き方の手本）

### 写真

写真は 1 食につき 1 枚か 2 枚上がってくる。

- **1 枚**: 食べる前の写真。全部食べたものとして「完食」と書く。聞かない
- **2 枚**: 食べる前と食べた後の写真。2 枚の差から、品目ごとにどれだけ食べたかを書く。後の写真に残っている量で、完食・ほとんど・半分くらい・少し・食べなかった のどれかにする

進め方:

- まず写真を食事ごとに分ける。同じ器・同じ献立が写っている写真が同じ食事。晩ごはんか朝ごはんかは、ぴよログの食事の時刻、写真の明るさや献立から決める
- 2 枚の組では、料理が多く残っている方を食べる前とする。どちらが前か分からなければ、その食事の欄は空けて保存する
- 1 食に 3 枚以上ある時や、組にならない写真がある時は、分からない食事の欄は空けて保存する
- 品目を、確からしさ（高い・中くらい・低い）付きで挙げる。低い物も、いちばん近い料理の名前で下書き保存し、聞かない。下書きに「？」などの印も付けない。合っていても、保護者が答えたり消したりする手間が出る。保存した後の返事にお知らせを 1 行だけ添える（5 を見る）
- 写真に写った子どもの様子（顔色など）は、保護者が気にしていそうな時だけ一言添える。診断はしない

## 3. 欄に分ける

欄ごとに、次の順で先にある物を使う。足りない欄だけを埋める。

1. **保護者が書いた文章**: 書いてある欄は、そのまま採る。言い回しを直したり、ぴよログや写真の内容で上書きしたりしない。食い違いがあっても保護者の文章を採る
2. **写真**: 食事の欄
3. **ぴよログ**: 排便・睡眠・体温・コメント。使っていない家庭もある

どの欄の話かを読み取って分ける。どの欄か分からない文は、コメントの欄に入れる。

### 夜に送られた言葉

夜に開くのは次の朝に出す連絡帳なので、言葉の「今日」「明日」は、連絡帳の中の夜と朝に読み替える。

- 夜の「今日の晩ごはん」「今日は 18 時半に寝た」「今夜のうんち」: 夜の欄（食事 夜、排便 夜）と入眠
- 夜の「明日の朝は〜」「朝ごはんはパンの予定」「明日のお迎えは 18 時パパ」: 朝の欄（食事 朝、排便 朝）、起床、検温、お迎え予定時間、コメント。夜のうちに決まっている朝のこともそのまま入れる

まだ起きていない朝のことを入れた欄は、入れたままにする。違っていれば、保護者が送信する前にアプリで見て話す。

### 聞かずに決めること

- **ぴよログに記録が無い排便**: 0 回とする。「うんちが出ない日もある」。回数や状態を聞かない（ぴよログを使っている家庭だけ）
- **体調・メモが無い**: コメントは空にする。「様子はふだん通りですか」と聞かない
- **保護者が残した物だけを言った時**: ほかは全部食べた。「ほかは全部食べましたか」と聞かない
- **体温の測定時間**: 15 分刻みに丸めた値を、はじめから下書きに書く（8:10 → 8:15）
- **どこにも無い欄**（睡眠、お迎えの時間と誰、ぴよログを使っていない家庭の排便・体温など）: 空のまま保存する。空いている欄は保存した後の返事で伝わるので、別に聞かない。保護者は空いている欄をあとで話せばよい

### 食事の欄

- `tmp/meal_history.json` があれば、出てくる料理名を写真を読む時の候補にする。写真の料理と見た目が似ている時だけその名前を使い、迷ったら、いちばん近い名前で保存する
- 同じく、写真やぴよログから埋める欄は、その家庭の前の書き方（品目の並べ方、区切りの記号、「完食」などの言い方、句読点）に合わせる。前の書き方と下の例が違う時は、前の書き方を優先する。保護者が書いた文章は、今まで通りそのまま使う
- 主食（ごはん・パンなど）も必ず品目に入れる。残した物があっても品目からは外さない
- 全部完食なら、品目を並べて最後に「（全て完食）」: `パン、バナナ、ヨーグルト、牛乳（全て完食）`
- 一部だけ残した時は、品目を全部並べて最後にまとめる: `ごはん、ハンバーグ、みかん、牛乳（ごはんは半分、ほかは完食）`
- いくつも残した時は、品目ごとに量を付ける: `カレー（半分くらい）、サラダ（少し）、ぶどう（完食）`

## 4. すぐ下書き保存する

確認を待たずに、下書きを `tmp/draft.json`（git に入らない）に書き、保存まで進める。欄と値の決まりは `docs/codmon-form.md`。

保存は実行の前に、「コドモンに保存します。10 秒ほどかかります。アプリを閉じても進みます」と伝える。保護者は朝いそがしいので、待たなくてよいことが分かるようにする。

```
python3 scripts/codmon_fill.py tmp/draft.json --save
```

- `draft.json` の形はスクリプトの先頭に書いてある。分からない欄は書かない（空のまま残る）
- 排便の状態は 普通・軟便・少量便・硬便・下痢便 のどれか。回数は 3 を超えたら 3
- `draft.json` に書いた欄だけが変わり、ほかの欄は入っている内容のまま残る
- お迎えは `"13時\nママ"` のように、時間と誰を改行で分ける
- 開く連絡帳は、午前は今日、12 時以降は明日。次の登園日が明日でない時（金曜の夜など）だけは、保存の前に保護者に 1 回だけ聞いて `--date 2026-11-09` のように指定する。保護者が答えずに別の話をしたり、会話を閉じたりしたら、決まりどおりの日を開く。一度決まった日は、この会話の間ずっと使い、聞き直さない
- 書いた欄に別の内容がすでに入っていると、何も変えずに止まり（終了コード 2）、入っている内容を表示する。保護者に見せて、上書きしてよいと言われた時だけ `--overwrite` を付けてやり直す。保護者が言い直した欄を入れ直す時は、上書きしてよいと言われたものとして `--overwrite` を付ける
- 開いた日の連絡帳がもう送信済みだと、何も変えずに止まる。そのまま保護者に伝える
- 保存した後に開き直して値を読み直す。入れた値が残っていなければ止まる（終了コード 3）。もう一度実行する
- 終わったら、表示された値（`values`）が下書きの中身と合っているかを自分で確かめる

送信は押さない。`tmp/draft.json` は終わったら消す。

保護者の言い直し（「さつまいもじゃなくて栗」「今朝ちょっと鼻水」など）が届いたら、その欄を入れ直して保存し、5 の形で返す。

## 5. 返事する

保護者は朝いそがしく、長い返事を読む暇がない。保護者は音声入力で話すことが多く、コドモンの画面を見ていないので、どこが空いているかだけは毎回伝える。

- 保存した後と、`--read` した後の返事は 1〜2 行にする。開いた日と、空いている欄だけを書く。実行結果の `date` と `empty` から作る。自分の記憶で書かない
- 写真から推測して入れた品目がある時だけ、お知らせを 1 行添える。確認は求めない
- 保存した値に合っていない欄があった時だけ、その欄を書く

  ```
  11月9日(月)の連絡帳に保存しました。
  空いている欄: 検温、お迎え予定時間。このまま話してください
  朝ごはんの「さつまいも」は写真から推測して入れました。違っていたら教えてください。
  ```

- 空いている欄が無ければ、「全部の欄が埋まりました。コドモンのアプリで内容を見て、送信を押してください」とだけ書く
- 空いている欄を 1 つずつ聞き返さない

### 全部の欄を見せる形

保護者が「全部見せて」「今どうなってる？」と頼んだ時だけ、`--read` の結果を **コドモンの画面と同じ欄・同じ並び** で見せる。どこから取ったか（文章・写真・ぴよログ）は書かない。入っていない欄は「（空）」と書く。

例:

```
排便
  夜: 0回
  朝: 普通 1回
食事
  夜: ごはん、カレー、ぶどう、牛乳（ごはんは半分、ほかは完食）
  朝: パン、バナナ、さつまいも、牛乳（全て完食）
検温: 36.8℃（6:15）
睡眠
  入眠: 20:45
  起床: 6:00
お迎え予定時間: 18時 ／ パパ
コメント: 朝だけ少しせき
```
