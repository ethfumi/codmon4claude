## 2026-11-03（火）

### ぴよログの記録の取り出し方

- 最初の調べでは「ぴよログに公開 API は無い。テキストの書き出しを手で渡すしかない」という結論になった。検索に古い情報しか出てこなかったのが原因
- 実際には 2026-09-15 に公式の読み取り専用 API「[データフィード](https://www.piyolog.com/app/piyolog/data_feed/ja/index.html)」が出ていた。アプリで発行した URL に GET すると、直近の記録が JSON で返る。無料プランでも直近 24 時間なら取れるので、毎朝前日分を読む用途に足りる
- 取れないもの: 写真、食事の中身（日時とメモだけ）。→ 晩ごはん・朝ごはんの中身は写真から Claude が読む形がちょうど合う

### 先行例と、このツールの立ち位置

- データフィードを使ってコドモンの連絡帳に自動で下書き保存するツール [kzh-h/codmon-piyolog](https://github.com/kzh-h/codmon-piyolog) がすでにあった。おかげで「コドモンの連絡帳には下書き保存がある」ことも分かった
- このツールは GCP の定期実行・Secret Manager・スプレッドシートを組み合わせる構成で、動かすにはクラウドの知識が要る
- そこで codmon4claude は、**エンジニアではない保護者が、Claude の Pro プランに入ってこのリポジトリを開くだけで使える**ことを目標にした。起点は定時ではなく、保護者が朝に食事の写真を上げた時。食事の中身は写真から読み、足りない所は会話で保護者に聞く

### どこで動かすか

- Claude Code のクラウドセッションなら、PC が無くてもスマホの Claude アプリから使える。公式ドキュメントで、Pro で使えること、リポジトリの `CLAUDE.md`・`.claude/` の設定がクラウドでも読まれることを確かめた
- 普通のチャットも検討したが、チャットからはログインやフォームの入力ができないので見送った
- 実際にクラウドセッションを立てて確かめた結果:
  - スマホから写真を添付できた。朝ごはんの写真から、品目と確からしさを表にし、分からない物は保護者に確かめる、という返事が返った
  - ぴよログ・コドモンへの通信は、クラウド環境のプロキシに 403 で止められた。既定のネットワーク設定（許可リスト）に入っていないため。環境の設定で「制限付き」にして `feed.piyolog.com` と `*.codmon.com` を足す必要がある
  - Playwright は入り、クラウド環境に入っている Chrome で起動できた
- 最初のクラウドセッションは、作業中のブランチが GitHub に無かったため始まらなかった。ブランチを push してから立て直した

### 迷わないための準備の点検

- ネットワークの許可、ぴよログの URL、コドモンのログイン情報と、最初の準備が 3 つある。スマホでドメインを手で打つのは保護者には重い
- そこで、セッションの始まりに準備を点検するフック（SessionStart）を作った。足りない物があれば、Claude が最初の返事で次の 1 手だけを、貼れる形で出す
- プロキシに止められた場合（CONNECT が 403）と、URL が間違っている場合（404）を分けて案内する。子どもの記録の中身は点検では出さず、件数だけ返す

### Claude の使い方

- 調べもの（ぴよログの連携、クラウドセッションの制約、チャットでできること）は、サブエージェントに公式ドキュメントを読ませ、出典 URL 付きで返させた。分からないことは「書いていない」と書かせて、推測と区別した
- クラウド環境で本当に何が届くかは、ドキュメントだけで決めず、別のクラウドセッションを立てて実測させた

### コドモンのログイン画面と、ぴよログの読み取り

- ネットワークの許可を足したあと、クラウドセッションからコドモンのログイン画面を開けた。画面は Firebase（`*.googleapis.com`、既定の許可で通る）を使う。計測や後払い決済の通信（Google Tag Manager、New Relic、Paidy）はプロキシに止められるが、画面は出るので許可しない
- ログイン画面の入力欄には `name` 属性が無い。自動入力では placeholder の文字や `type=password` を目印に欄を探す
- ぴよログのデータフィードを日本時間に直し、体温・食事・うんち・睡眠・体調・メモに分けて並べるスクリプトを作った。テストは公式の仕様に沿って作った架空の記録で行い、本物の記録はリポジトリに入れない
- 朝の流れ（記録を読む → 写真から食事を読む → 下書きを見せて確かめる → コドモンに下書き保存）をスキルにした。コドモンへの入力の手順は、連絡帳の画面の欄を確かめてから足す

## 2026-11-04（水）

- コドモン保護者 Web 版の連絡帳の入力欄を、Playwright で開いて一覧にした（[docs/codmon-form.md](codmon-form.md)）。排便（夜・朝の状態と回数）、食事（夜・朝の自由記述）、睡眠（入眠・起床）、検温（体温・測定時間）、お迎え予定時間、コメント。「下書き保存」ボタンがあるので、このツールはそこまでを押し、「送信する」は保護者に任せる
- 欄に `name` 属性が無く、select の多くは選択肢の一覧から選ぶ形なので、見出しの文言と並び順で欄を探す。ぴよログの記録との対応も同じ資料にまとめた
- ぴよログの URL とコドモンのパスワードを、ふだん使うクラウド環境（Default）に入れると、ほかのリポジトリのセッションにも渡る。連絡帳専用の環境「codmon」を作り、そこにだけ入れる手順にした
- クラウド環境の環境変数は、保存してもすぐには入らなかった。クラウドセッションで値を出し入れして確かめると、作業場所が立ち上がる時（新しいセッション、または 10 分ほど使わずに置いた後）に入る。ネットワークの許可はすぐ効く。手順と点検の案内をこれに合わせた
- Windows とクラウドで同じファイルを編集すると、改行の違いでファイル全体が衝突した。`.gitattributes` で LF にそろえた
- コドモンの連絡帳に入力して下書き保存するスクリプトを作った。保存を押さずに埋めるだけのお試しで、全部の欄が埋まることを確かめた。お試しの中で、画面を開いた直後は欄が空で、保存済みの内容が数秒遅れて読み込まれることが分かった。読み込みを待ってから、すでに内容が入っている日は何も変えずに止まり、保護者に上書きしてよいか聞く形にした
- 連絡帳には、食事をどこまで食べたかを書く。写真を 1 食につき 1 枚か 2 枚にした。1 枚なら食べる前の写真として完食、2 枚なら食べる前と後の差から品目ごとの量を書く。README に使い方を書いた
- 保護者には決まった書き方の文があることが多い。コドモンの連絡帳は欄が分かれていてまとめて貼れないので、保護者が書いた文章を Claude が受け取って欄ごとに分けて入れ、書かれていない欄だけをぴよログと写真から埋める順にした。保護者の文章は言い直さず、そのまま使う

## 2026-11-05（木）

- 初めて朝の流れを通しで使った。保護者から「だいぶだるい」と言われたので、聞きすぎた所と、つまずいた所を直した
- 聞きすぎた所: ぴよログに記録の無い排便の回数、「様子はふだん通りか」、残した物以外を食べたか、を何度も聞いていた。記録が無ければ 0 回・コメントは空、残した物だけ言われたらほかは完食、として聞かないことをスキルに書いた
- 下書きの見せ方: 欄の名前や並びが自己流で、主食のごはんが品目から抜けていた。コドモンの画面と同じ欄・並び（排便 夜/朝、食事 夜/朝、検温、睡眠、お迎え予定時間、コメント）で見せ、主食は必ず入れる形にした
- コドモンの入力でつまずいた所:
  - クラウドの時計は UTC なので、日本の朝 9 時前にブラウザを開くと前の日（送信済み）の連絡帳が出た。ブラウザを日本時間で開き、画面の日付が日本の今日でなければ止めるようにした。送信済みの日も止める
  - 食事の 2 つ目の欄に入れた値が、画面に残らない事があった。打ち込んで欄を離れる形にし、入れた後と保存して開き直した後に値を読み直して確かめるようにした
- 入力が遅いと言われたので測った。読むだけで 25 秒、保存まで 45 秒ほどかかっていた。URL を直接開くと保存済みの内容が出るまで 6 秒ほどかかり、さらに固定で 5 秒待っていた。下のタブから開くと 1 秒ほどで出るので、タブから開き、内容が入ったらすぐ進むようにした。画像・フォント・計測の読み込みも止めた。保存は、保存の通信が返るまで待つ。読むだけで 11 秒、保存まで 20 秒ほどになった。残りの多くはコドモンのログインの待ち
- 保護者に初めて準備の手順を通してもらった。「『codmon』の環境の設定を開いて」という案内でコドモンのアプリを開きに行ったので、環境の名前を決めつけるのをやめ、「Claude の環境の設定」と呼ぶことにした。ブラウザを開く案内もやめた。Claude アプリの中で設定できた
- ぴよログを使わない家庭もあるので、ぴよログを無くても使えるようにした。URL が無ければ点検でも足りない物に数えない
- 夜のうちに入力する家庭もあるので、届いた分をその場で下書き保存できるようにした。「内容が入っていたら全部止める」をやめ、下書きに書いた欄だけを変えて、別の内容が入っている欄がある時だけ止める形にした。開く日は、午前は今日、12 時以降は明日にした
- 動作確認の会話が誤って出した PR を履歴から消すため、公開前にリポジトリを作り直した。コードとコミットはそのまま残したが、それまでの PR の一覧（24 件）は無くなった。コミットの「Merge pull request #N」の番号はその時のもの
- 文章・写真からの入力を保護者に試してもらい、次を直した: 環境の名前で案内するとコドモンのアプリと取り違える、ブラウザを開かせなくても Claude アプリで設定できる、ぴよログの URL の取り方を最初から案内する、夜に送った内容はその場で次の朝の連絡帳に下書き保存する、日付を移った直後に前の日の内容を読まない
