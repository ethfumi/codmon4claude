# はじめの準備

最初に 1 回だけ行います。スマホだけでできます。

用意するもの:

- Claude の有料プラン（Pro 以上）
- コドモンのログインに使うメールアドレスとパスワード
- GitHub のアカウント（無料。持っていなければ 1 で作ります）
- ぴよログ（使っている人だけ。iOS 版 9.4.0 以上）

## Claude に案内してもらう

Claude アプリのチャットで、次の文を送ります。この後の手順を 1 つずつ案内してくれます。

```
https://github.com/ethfumi/codmon4claude/blob/main/docs/setup.md を読んで、この準備を 1 つずつ案内してください。一度に出す操作は 1 つだけにしてください。パスワードと URL は、この会話に貼らせないでください。
```

コドモンのパスワードとぴよログの URL は、チャットに貼らず、2 の環境の設定にだけ入れます。

## 1. GitHub につなぐ

Claude のクラウドセッションは、GitHub のアカウントをつないで使います。自分で開発はしないので、アカウントを作ってつなぐだけで大丈夫です。

1. アカウントが無ければ、https://github.com/signup で作る（無料）
2. Claude アプリの Code タブを開き、GitHub につなぐボタンを押して、1 のアカウントでログインする

## 2. 連絡帳専用のクラウド環境を作る

コドモンのパスワードとぴよログの URL は、クラウド環境に入れます。クラウド環境に入れた物は、その環境で始めたすべてのセッションに入るので、ふだん使っている環境（「Default」など）には入れず、連絡帳専用の環境を作ります。

クラウド環境は Claude の中の設定です。コドモンのアプリを開く必要はありません。

### 環境を作ってもらう

Claude アプリの Code タブの新しいセッションの画面で、リポジトリに `ethfumi/codmon4claude` を選び（一覧に無ければ、検索の欄に貼ります）、次の文を送ります。クラウド環境は今のままで構いません。

```
連絡帳を使う準備をしてください。
```

Claude が、ぴよログを使っているかを聞きます。答えると、環境を作る案のカードを出します。内容を見て承認すると、環境ができて、ネットワークの許可も入ります。

**カードが出ない時:** 入力欄の下のクラウド環境を押し、「環境を選択」→「新しい環境」と進んで作ります。名前は何でも構いません（例: `連絡帳`）。同じ画面から環境の設定を開き、「ネットワークアクセス」を「制限付き」にして、「許可されたドメイン」に次の行を貼り、「パッケージマネージャーを許可」にはチェックを入れたままにして保存します。ぴよログを使っていなければ、`feed.piyolog.com` の行は要りません。

```
parents.codmon.com
ps-api.codmon.com
feed.piyolog.com
```

### 環境変数

Code タブの新しいセッションの画面で、連絡帳専用の環境の設定を開き、「環境変数」の欄に入れます。パスワードと URL は、会話には貼らないでください。

環境変数は、この環境を使えるあなただけが見られます。リポジトリには書き込まれません。ほかの環境のセッションには入りません。

**コドモン**

次の 2 行を貼り、`=` の右側を自分の値に書き換えます。コドモンのアプリにログインする時のメールアドレスとパスワードです。

```
CODMON_EMAIL=コドモンのメールアドレス
CODMON_PASSWORD=コドモンのパスワード
```

ぴよログを使っていれば、続けて下のぴよログの欄も入れます。使っていなければ、「変更を保存」を押して 3 へ進みます。文章と写真だけでも連絡帳を入れられます。

**ぴよログ（使っている人だけ）**

手で打たずに済むように、この順で貼ります。

ぴよログのアプリで「設定」→「データフィード」を開き、URL をコピーします。

- **フィードがもうある時**: そのフィードを押す → 「フィードURLを表示」→「URLをコピー」
- **フィードがまだ無い時**: 「新しいフィードを作成」→ 対象の子どもを選ぶ → 取得期間は「24時間」、有効期限はいちばん長いものを選ぶ →「フィードを作成」→「フィードURLを表示」→「URLをコピー」
- **「データフィード」が出ない時**: ぴよログを最新にします（9.4.0 以上が必要です）
- **権限が無いと出る時**: 記録を共有している家族のうち、管理権限のある人のアプリで同じ操作をして、URL を送ってもらいます

Claude の「環境変数」の欄で改行して URL を貼り、そのすぐ前に次の文字を貼ります。

```
PIYOLOG_FEED_URL=
```

「変更を保存」を押します。

この URL はパスワードと同じです。どこかに貼って公開しないでください。無料プランの URL は 90 日で切れます。切れたら同じ手順で作り直して入れ替えます。

## 3. 連絡帳専用の環境で始める

Claude アプリの Code タブの新しいセッションの画面で、次の 2 つを選びます。

- クラウド環境: 連絡帳専用の環境
- リポジトリ: `ethfumi/codmon4claude`（一覧に無ければ、検索の欄に貼ります）

連絡帳を頼む時は、毎回この 2 つを選んで始めます。始めると、Claude が準備の点検をして、足りない所があれば教えてくれます。

新しいセッションの画面では、前の会話で使ったリポジトリや環境が選ばれたままのことがあります。送る前に、入力欄の下のリポジトリが `ethfumi/codmon4claude`、クラウド環境が連絡帳専用の環境になっているかを見ます。

### 別のリポジトリのまま始めてしまった時

リポジトリを選び直さずに始めた会話では、連絡帳の決まりが読まれず、返事が英語になったり、準備の点検が動かなかったりします。新しいセッションで 2 つを選び直すのがいちばん確実です。

選び直せない時は、クラウド環境が連絡帳専用の環境になっていれば、その会話に次の文を貼って送ります。Claude が連絡帳のリポジトリを取ってきて、決まりを読み、準備の点検をします。

```
https://github.com/ethfumi/codmon4claude をこの会話に取ってきて、連絡帳に使いたいです。取ってきたら、その中の CLAUDE.md と .claude/skills/renrakucho/SKILL.md を読んで、その決まりどおりに日本語で進めてください。続けて、.claude/settings.json の SessionStart のフックと同じコマンドを取ってきたリポジトリの中で実行して、準備の点検の結果を教えてください。
```

この形では、スクリプトを動かすたびに「今回のみ許可」の確認が出ることがあります。押して進めて構いません。2 つを選んで始めた会話では出ません。

クラウド環境が連絡帳専用の環境でない時は、コドモンのパスワードが入っていないので、この文では使えません。新しいセッションで選び直します。

ネットワークの許可は、保存するとすぐ効きます。環境変数は、保存してもすぐには入らず、作業場所が立ち上がる時に入ります。

- 新しいセッションを始める時に連絡帳専用の環境を選べば、最初から入っています
- 今の会話のまま続ける時は、10 分ほど何も送らずに置いてから、何か送ります。作業場所が立ち上がり直して、その時の値が入ります。次の朝に「連絡帳お願い」と送るのでも構いません
