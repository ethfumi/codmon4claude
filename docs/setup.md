# はじめの準備

最初に 1 回だけ行います。スマホだけでできます。

用意するもの:

- Claude の有料プラン（Pro 以上）
- ぴよログ（iOS 版 9.4.0 以上）
- コドモンのログインに使うメールアドレスとパスワード

## 1. ぴよログのデータフィードの URL を取る

1. ぴよログの「設定」→「データフィード」を開く
2. 「新しいフィードを作成」を押す
3. 対象の子どもを選び、取得期間は「24時間」、有効期限はいちばん長いものを選ぶ
4. 「フィードを作成」を押す
5. 「フィードURLを表示」→「URLをコピー」

この URL はパスワードと同じです。人に送ったり、どこかに貼って公開したりしないでください。

無料プランの URL は 90 日で切れます。切れたら同じ手順で作り直し、4 の手順で環境変数を入れ替えます。

## 2. クラウド環境の設定を開く

Safari などのブラウザで https://claude.ai/code を開き、このリポジトリのセッションの題名の横の「∨」から、クラウド環境の編集を開きます。

## 3. ネットワークの許可を足す

「ネットワークアクセス」を開き、「制限付き」を選んで、「許可されたドメイン」に次の 2 行をそのまま貼ります。

```
feed.piyolog.com
*.codmon.com
```

「パッケージマネージャーを許可」にはチェックを入れたままにします。「変更を保存」を押します。

## 4. 環境変数を入れる

同じ画面の環境変数の欄に、次の 3 行を貼り、`=` の右側を自分の値に書き換えます。

```
PIYOLOG_FEED_URL=ここに1でコピーしたURL
CODMON_EMAIL=コドモンのメールアドレス
CODMON_PASSWORD=コドモンのパスワード
```

環境変数は、この環境を使えるあなただけが見られます。リポジトリには書き込まれません。

## 5. 新しいセッションを始める

環境変数は、新しく始めたセッションから効きます。新しいセッションを始めると、Claude が準備の点検をして、足りない所があれば教えてくれます。
