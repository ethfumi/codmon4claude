# はじめの準備

最初に 1 回だけ行います。スマホだけでできます。

用意するもの:

- Claude の有料プラン（Pro 以上）
- ぴよログ（使っている人だけ。iOS 版 9.4.0 以上）
- コドモンのログインに使うメールアドレスとパスワード
- GitHub のアカウント（無料。持っていなければ 0 で作ります）

## 0. GitHub につなぐ

Claude のクラウドセッションは、GitHub のアカウントをつないで使います。自分で開発はしないので、アカウントを作ってつなぐだけで大丈夫です。

1. https://github.com/signup でアカウントを作る（無料）
2. Claude アプリの Code タブを開き、GitHub につなぐボタンを押して、1 のアカウントでログインする

## 1. ぴよログのデータフィードの URL を用意する

ぴよログを使っている人だけの手順です。使っていなければ飛ばして構いません。ぴよログが無くても、文章と写真で連絡帳を入れられます。

URL は、4 の手順の中でぴよログのアプリから取ります。ここでは、取れるかを先に確かめます。

ぴよログのアプリで「設定」→「データフィード」を開きます。

- **フィードがもうある時**: そのフィードを押す → 「フィードURLを表示」→「URLをコピー」
- **フィードがまだ無い時**: 「新しいフィードを作成」→ 対象の子どもを選ぶ → 取得期間は「24時間」、有効期限はいちばん長いものを選ぶ →「フィードを作成」→「フィードURLを表示」→「URLをコピー」
- **「データフィード」が出ない時**: ぴよログを最新にします（9.4.0 以上が必要です）
- **権限が無いと出る時**: 記録を共有している家族のうち、管理権限のある人のアプリで同じ操作をして、URL を送ってもらいます

この URL はパスワードと同じです。どこかに貼って公開しないでください。

無料プランの URL は 90 日で切れます。切れたら同じ手順で作り直し、4 の手順で入れ替えます。

## 2. 連絡帳専用のクラウド環境を作る

ぴよログの URL とコドモンのパスワードは、クラウド環境に入れます。クラウド環境に入れた物は、その環境で始めたすべてのセッションに入るので、ふだん使っている環境（「Default」など）には入れず、連絡帳専用の環境を作ります。

クラウド環境は Claude の中の設定です。コドモンのアプリを開く必要はありません。

Claude アプリの Code タブで、新しいセッションの画面の入力欄の下にある「Default」を押し、「環境を選択」→「新しい環境」と進みます。名前は何でも構いません（例: `連絡帳`）。

3 と 4 の設定は、この連絡帳専用の環境に入れます。

## 3. ネットワークの許可を足す

Claude アプリの Code タブで、新しいセッションの画面（最初に環境を選ぶ所）に戻ると、環境の設定を開けます。そこで連絡帳専用の環境の設定を開きます。

「ネットワークアクセス」を開き、「制限付き」を選んで、「許可されたドメイン」に次の 2 行をそのまま貼ります。

```
feed.piyolog.com
*.codmon.com
```

「パッケージマネージャーを許可」にはチェックを入れたままにします。「変更を保存」を押します。

## 4. 環境変数を入れる

同じ Claude の環境の設定の「環境変数」の欄に入れます。手で打たずに済むように、この順で貼ります。ぴよログを使っていなければ、4 から始めます。

1. ぴよログのアプリで、1 の手順で URL をコピーする
2. Claude の「環境変数」の欄に貼る
3. 貼った URL のすぐ前に、次の文字を貼る

```
PIYOLOG_FEED_URL=
```

4. 改行して、次の 2 行を貼り、`=` の右側を自分の値に書き換える。コドモンのアプリにログインする時のメールアドレスとパスワードです

```
CODMON_EMAIL=コドモンのメールアドレス
CODMON_PASSWORD=コドモンのパスワード
```

5. 「変更を保存」を押す

環境変数は、この環境を使えるあなただけが見られます。リポジトリには書き込まれません。ほかの環境のセッションには入りません。

## 5. 連絡帳専用の環境で始める

ネットワークの許可は、保存するとすぐ効きます。環境変数は、保存してもすぐには入らず、作業場所が立ち上がる時に入ります。

- 新しいセッションを始める時に、クラウド環境に連絡帳専用の環境を選べば、最初から入っています
- 今の会話のまま続ける時は、10 分ほど何も送らずに置いてから、何か送ります。作業場所が立ち上がり直して、その時の値が入ります。次の朝に「連絡帳お願い」と送るのでも構いません

連絡帳を頼む時は、毎回連絡帳専用の環境で始めます。始めると、Claude が準備の点検をして、足りない所があれば教えてくれます。
