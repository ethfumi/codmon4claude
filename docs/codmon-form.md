# コドモンの連絡帳の入力欄

保護者 Web 版（https://parents.codmon.com/contact 、下のタブの「連絡」）の連絡帳の欄。入力欄に `name` 属性が無いので、見出しの文言・placeholder・並び順で探す。園によって欄が違う可能性がある。

## ログイン

1. https://parents.codmon.com/ を開き、「すでにアカウントをお持ちの方」を押す
2. placeholder「メールアドレス」と `type=password` の欄に入力し、「ログインする」を押す
3. ログイン後は `/home`。下のタブの「連絡」で `/contact` に移る

## 画面の上

- 連絡先: `select`（子ども > 施設）。子どもが複数いる時はここで選ぶ
- 日付: 「‹ 前日」「11月4日(水)」「翌日 ›」。開いた時はその日

## 欄

| 区分 | 見出し | 欄 | 種類 | 選べる値 |
|---|---|---|---|---|
| 排便 | 夜の調子はいかがでしたか？ | 状態 | select | 普通 / 軟便 / 少量便 / 硬便 / 下痢便 |
| 排便 | 夜の調子はいかがでしたか？ | 回数 | select | 0回〜3回 |
| 排便 | 朝の調子はいかがでしたか？ | 状態 | select | 同上 |
| 排便 | 朝の調子はいかがでしたか？ | 回数 | select | 0回〜3回 |
| 食事 | 夜のお食事内容を教えてください | 食事内容 | textarea | 自由記述 |
| 食事 | 朝のお食事内容を教えてください | 食事内容 | textarea | 自由記述 |
| 睡眠 | 昨日の眠った時間帯はいつ頃でしたか？ | 入眠 | select | 15 分刻み |
| 睡眠 | 昨日の眠った時間帯はいつ頃でしたか？ | 起床 | select | 15 分刻み |
| 検温 | 本日の体温は何度でしたか？ | 体温 | select | 35.0℃〜42.0℃（0.1 刻み） |
| 検温 | 本日の体温は何度でしたか？ | 測定時間 | select | 15 分刻み |
| お迎え予定時間 | 下記の内容をご入力ください | 時間・誰 | textarea | 自由記述 |
| コメント | 本日のお子さまのご様子などを教えてください | お子さまの様子について | textarea | 自由記述 |

select の最初の項目（「状態」「回数」「入眠」など）は未選択を表す見出し。時刻の select は見出しが途中に入っている（例: 入眠は 20:45 と 21:00 の間）。

## ボタン

- 「下書き保存」: このツールが押すのはこれだけ
- 「送信する」: 押さない。送信は保護者が自分で押す
- 「連絡帳は、当日9:00までに送信お願い致します」と出る

同じ画面の下に、連絡帳とは別の「お迎え連絡」「その他の連絡」の送信ボタンもある。押さない。

## ぴよログとの対応

| 欄 | ぴよログ |
|---|---|
| 排便 夜・朝 | `Poop` を時刻で夜と朝に分ける。回数は件数（3 回を超えたら 3 回）。状態は `details.hardness`（diarrhea→下痢便、soft→軟便、hard→硬便、normal→普通、`amount` が minimum・small なら少量便） |
| 食事 夜・朝 | 写真から読む。ぴよログの `Meal` のメモがあれば足す |
| 入眠・起床 | `Sleep`・`WakeUp` を 15 分に丸める |
| 体温・測定時間 | 当日朝の `Temperature`。時刻は 15 分に丸める |
| コメント | ぴよログの体調（`Cough` など）とメモ、保護者のひとこと |
| お迎え予定時間 | 保護者に聞く |
