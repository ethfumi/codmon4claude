# Muse で使う場合（未検証）

Muse は無料でも試せるプランがあるので、Claude の有料プランが無い保護者の入口になる可能性があります。ただし、連絡帳への入力まで通したことはありません。ここに書く流れは案です。

## 確かめたこと（2026-11-06）

| 確認 | 結果 |
| --- | --- |
| python3、pip | 使える |
| Playwright でヘッドレスの Chrome を起動 | できる |
| その Chrome からコドモンを開く | できない（`ERR_TUNNEL_CONNECTION_FAILED`。example.com でも同じ） |
| Muse のブラウザのツールからコドモンを開く | 開ける（白い画面が約 15 秒） |
| 公開リポジトリの clone | できる |

`scripts/codmon_fill.py` は Playwright を使うので、Muse ではそのまま動きません。

## 流れの案

1. Muse にこのリポジトリを読ませる
2. 保護者が連絡帳に書きたいことと、食事の写真を送る
3. Muse が `.claude/skills/renrakucho/SKILL.md` の決まりで欄に分け、下書きを見せる
4. 保護者が OK と言ったら、Muse のブラウザで `docs/codmon-form.md` の欄に入力し、「下書き保存」を押す
5. 保護者がコドモンのアプリで内容を見て、送信を押す

## シークレットと子どもの情報

試す前に、次を決まりにします。

- **コドモンのパスワード:** 会話に書かない。ファイルにも書かない。ログインの画面で保護者が手で入れる
- **ぴよログの URL:** 渡さない。URL を知っていれば記録を読めるので、会話や Muse の記憶に残さない。文章と写真だけで入力する
- **学習の設定:** 使う前に、アプリの設定で AI の学習に使う設定を確かめ、止める
- **渡る情報:** ログインすると、お子さんの名前や記録が画面に出て、Muse に渡る。家族で話してから使う
- **写真:** 料理だけを撮る。お子さんを写さない
- **送信:** 押させない

## まだ確かめていないこと

- 無料の範囲で 1 回の入力が終わるか

- Muse の学習の設定と、データの扱いの日本向けの条件
- コドモンの規約から見て、Muse に入力させてよいか（第 15 条(2) が広い）
