# Muse で使う場合

Muse は無料でも試せるプランがあるので、Claude の有料プランが無い保護者の入口になる可能性があります。コドモンの下書き保存までは通りました。無料の範囲とデータの扱いは確かめていません。

## 確かめたこと（2026-11-06）

| 確認 | 結果 |
| --- | --- |
| python3、pip | 使える |
| Playwright でヘッドレスの Chrome を起動 | できる |
| その Chrome からコドモンを開く | できない（`ERR_TUNNEL_CONNECTION_FAILED`。example.com でも同じ。curl は届く） |
| Muse のブラウザからコドモンを開く | 開ける |
| ログイン | Secure Vault に入れた認証情報で入れた。追加の認証は無し |
| テストの値を入力して下書き保存 | できた。読み込み直しても残っていた |
| 食事の写真から品目を読む | できる。小さいカップのヨーグルトをゼリーと読むなどの間違いはある |
| 公開リポジトリの clone | できる |
| ぴよログの URL を Secure Vault に入れて読む | できない（どの形でも 404。ブラウザでは同じ URL が開く） |

段ごとの時間（秒はブラウザの時刻が分単位なので推定、保存なし）:

| 段 | 時間 |
| --- | --- |
| ページの読み込み | 約 20 秒（白い画面が 15 秒） |
| サインイン | 0 秒（前のセッションのログインが残っていた） |
| 日付の移動 | 約 5 秒 |
| 5 欄の入力 | 約 3 秒 |
| 合計 | 約 28 秒 |

保存と確認まで通した時は約 3 分かかりました。差の大半は、操作の承認待ち（約 1 分強）と保存・確認の読み込みです。日付を移った直後は前の日の表示が残ることがあり、読み込み直して待つと正しく出ます。

`scripts/codmon_fill.py` は Playwright を使うので、Muse ではそのまま動きません。

## 流れ

1. コドモンのログイン情報を Secure Vault に入れる
2. Muse にこのリポジトリを読ませる
3. 保護者が連絡帳に書きたいことと、食事の写真を送る
4. Muse が `.claude/skills/renrakucho/SKILL.md` の決まりで欄に分け、下書きを見せる
5. 保護者が OK と言ったら、Muse のブラウザで `docs/codmon-form.md` の欄に入力し、「下書き保存」を押す
6. 読み込み直して、入れた値が残っているかを見る
7. 保護者がコドモンのアプリで内容を見て、送信を押す

ぴよログの記録は読めないので、排便・体温・睡眠は保護者が文章で送ります。

## シークレットと子どもの情報

- **コドモンのパスワード:** 会話とファイルに書かない。Secure Vault に入れる
- **ぴよログの URL:** 渡さない。URL を知っていれば記録を読めるので、会話や Muse の記憶に残さない
- **ぴよログの記録:** 保存せず、コミットしない
- **学習の設定:** 使う前に、アプリの設定で AI の学習に使う設定を確かめ、止める
- **渡る情報:** ログインすると、お子さんの名前や記録が画面に出て、Muse に渡る。家族で話してから使う
- **写真:** 料理だけを撮る。お子さんを写さない
- **送信:** 押させない

## まだ確かめていないこと

- 無料の範囲で 1 回の入力が終わるか
- Muse の学習の設定と、データの扱いの日本向けの条件
- 手順の文書だけで、別の保護者が迷わず始められるか
- コドモンの規約から見て、Muse に入力させてよいか（第 15 条(2) が広い）
